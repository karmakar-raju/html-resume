## 📌 About the Project

This project is a personal resume website developed entirely using **HTML5** as part of my journey into web development.

The goal was to understand how webpages are structured and how personal, educational, and professional information can be organized using fundamental HTML elements.

Although this is a beginner-level project, it represents an important milestone in my journey as a Computer Science and Engineering student.

## 🎯 Project Objectives

- Understand the fundamental structure of an HTML document.
- Practice using semantic and basic HTML elements.
- Organize resume information into clear, readable sections.
- Learn how to create hyperlinks and structure webpage content.
- Get familiar with GitHub repositories and project documentation.

## 🛠️ Technologies Used

| Technology | Purpose |
| --- | --- |
| HTML5 | Structure and content of the resume |
| GitHub | Source code hosting and version control |

## 📄 Resume Sections

The webpage organizes resume information into relevant sections, depending on the content included in the current version.

- Personal Information
- Career Objective
- Education
- Technical Skills
- Projects and Achievements
- Interests and Hobbies
- Contact Information

## 🚀 Getting Started

You can view or run this project locally by following these steps:

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.

No additional installations or dependencies are required.
